# Personal website starter

A locally runnable React app with a small Node development API. It is not deployed.

## Start it

1. Open this folder in VS Code.
2. Run `npm install` once if dependencies are missing.
3. Run `npm run dev` in the integrated terminal.
4. Open the local URL printed by Vite.

## Customize

- Page content: `src/pages/`.
- Shared responsive styling: `assets/css/site.css`.
- React navigation and resource filtering: `src/main.jsx`.
- Replace the placeholder identity, images, contact details, and sample cards with your own content.
- The blue palette is retained from the design reference.
